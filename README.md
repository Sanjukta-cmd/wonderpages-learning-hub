# WonderPages Learning Hub

An interactive PDF worksheet reader by Sanjukta Sahoo. Users select a PDF from their own device; workbook PDFs are not included in this repository.

## Features
- Read local worksheet PDFs with PDF.js
- Draw and erase annotations
- Save marks and progress locally in the browser
- Export a marked PDF or an answers backup
- Earn page stars and download a chapter completion certificate

## Run locally
Open index.html in a modern browser with an internet connection. PDF.js and pdf-lib are loaded from CDNs.

## Publish with GitHub Pages
1. Upload these files to the root of your repository on the main branch.
2. Open Settings → Pages in GitHub.
3. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then click Save.
4. Wait for GitHub Pages to publish the site.

## Privacy and storage
Selected PDFs, notes, drawings, stars, and progress are stored in this browser on this device. This repository includes no workbook PDFs or saved learner data.
